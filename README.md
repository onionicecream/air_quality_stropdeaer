# Air Quality Device - "Strop de Aer" workshop

- helped assemble an air-quality monitoring device during a workshop with the start-up [Strop de Aer](https://www.stropdeaer.ro/monitorizare-in-targu-mures/)
- device built for their national-wide monitoring network (the unit I worked on was deployed in Târgu Mureș)
- measures  PM2.5 / PM10, temperature and humidity
- part of the Robotics and Automation Club, Palatul Copiilor Târgu Mureș (2019–2021)
